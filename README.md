# Kenneth Florez Portfolio

Production portfolio for Kenneth Florez, focused on lead and senior network
engineering work across enterprise networking, wireless, SD-WAN, campus core
modernization, observability, and network automation.

## Development

```bash
npm run dev
```

Open `http://localhost:3000` to review the site locally.

## Production Build

```bash
npm run build
```

The site is configured for static export through `next.config.ts`.
